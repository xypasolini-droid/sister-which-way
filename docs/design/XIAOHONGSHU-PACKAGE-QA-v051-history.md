## 资源与清晰度

包内62项美术资源。五幅1672×941结尾WebP按原字节复制，SHA核对，不再重压；其他在用PNG保持各自原始尺寸，采用高质量WebP编码，透明通道逐像素一致。饱和细节不能满足误差预算的火苗图使用无损WebP。没有缩图、裁切或重新绘制。

RGB高质量编码是**有损编码**，不能称为全包无损。构建按透明度合成后的PSNR核对，低于38 dB会升级质量、尝试近无损，仍不合格则保留无损；最终最小合成PSNR约38.13 dB。该指标用于编码误差检查，不等同主观画质认证。已实际对照父亲坐姿的原图与编码图，面部、衣纹、信纸与完整双腿没有发生几何变化。源PNG与结尾母版继续保存在项目中。

资源清单来自全部新路线和每一镜演出，还包括常驻隐藏角色、fallback与6项有界历史视觉资源（诊所、旅行室内、获救父亲及姐姐三种伤姿）。没有宣称穷举了所有旧30节点版本的视觉路径；原网页保留全部历史素材。

图片首次失败会原路径重试一次，仍失败显示轻量重试按钮，不把女主换成另一身份，也不隐藏人物状态。
