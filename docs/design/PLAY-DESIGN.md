# 八幕短篇：单选、短演出、五种成长

版本0.4.0，2026-11-07。此文覆盖旧版整理物件、选衣、算账小游戏的设计。旧实现记录仅保留在带版本的历史验收中。

每幕直接单选故事行动，立即推进；没有收齐物件、核对算术或“选择下一步”。可选对白和手记承载长文，主屏保留一句目标及少量选项。

关键压迫过程用自动短镜头：摊前赶人、全家目睹抓捕、母亲被拦并遭打/女孩伸手去扶、拒售和举棍逼退、武装者胁迫孩子劳动、远亲强迁、北门枪火。施暴者与阿明是不同人物。演出可以暂停、跳过、重看，开面板或隐藏页面时暂停；演出本身不修改分支状态，也不替玩家作决定。

人物使用持续存在的九个槽位，普通对话切换不重播入场。动作由实际不同姿势呈现；手臂与距离、父亲双腿完整但跛行用拐、母亲公共外罩、少女男装小帽、受伤后的恢复都属于舞台状态。父亲身体设定遵守用户更正，旧版肢体缺失推断已[撤回](DETAIL-AUDIT.md)。拒绝强迁的红轿车与接应离城的露天货车分开，登车后乘客按背景同一透视绘制。

默认路线八次决定，五结局对应女主的成长：带父亲回家、自选离城、学会共同承担，以及成年后的女性守护者和自治建设者两个梦。写信、等待、借住、课堂或分住是生活前情，不再独立充当结局。真实路径决定现实结果；梦不消除现实伤势。
