# 场景行动改版 · 设计约定

本轮目标：玩家在彩色纸片舞台里观察、照护、整理、核对与表达，选择或完成操作后直接看见后果。一次旅程仍是有限的分支故事；不以操作速度或答题正确率衡量受压迫者是否值得得到帮助。

## 主循环与画面

默认新局为八幕短篇，路径为 `n01 → n02 → n06 → n07 → n09/n10/n13 → n18 → n25/n21/n22 → n30 → 结局`。每个合法分支固定八次决定；完整篇只用于兼容旧存档。母亲寻父受打、女孩购食受拒与陪幼弟讲故事合并到 n06 前的过场，保留伤势、饥饿和人物知道的事实。

一般节点直接进入可操作场景，最多三个可见热点。热点带来决定所需的信息、角色回应或一个短活动。单选路线与人物回应点下即调用对应行动；整理物件选齐所需项目即行动；核账算错可改，正确点“核对”直接推进。不再设置“选择下一步”或活动完成后的最终确认层。随时可听对白、选当前行动或写自己的决定，终章保留梦境入口，全部分支保持可达。n02 抓捕保留四拍演出；短篇 n06 用两句对白交代此前的伤害，再进入变装。完整篇 n03 仍先演出母亲遭打。短篇最后一次决定后直接呈现结局与短摘要。

使用已有 Next.js / React / TypeScript / GSAP 舞台、人物素材、Vitest 与可重放的分支规则。角色持续占据同一 DOM 槽位，普通切句、热点切换、开行囊、选择模式不重播入场，不改变同一视口的角色比例。真正的换场、衣着与人物去向才改变舞台。

画面保持彩色纸片质感，界面延续原有黑白磨砂；沿用现有 `--serif` / `--sans` 字体，不引入新字体与色板。主要界面色为近黑透明玻璃、白色行动、灰白说明、白色焦点与石墨描边；反馈以短句、实物和选中标记表达。视觉辨识点是场景内的行动位置，而不是更多卡片或循环粒子。

运动仅承担状态反馈。普通阅读静止，真实位移柔和过渡；减少运动时仍保留相同最终位置、在场事实、活动反馈与按钮。移动端重排操作区，所有核心动作提供原生按钮或输入，不依赖拖拽、悬停、长按或精确手速。

## 决策与边界

候选方向包括更长对白、迁移到完整叙事引擎、增加场景操作。选择场景操作，因为现有分支与存档已经完整，而主画面此前没有行动入口。更长对白会增加相同输入；迁移 inkjs / XState 会增加改造成本，且不直接解决当前问题。

短篇单独编写节点跳转、条件和后果，不把完整篇的选择偷偷自动执行。两种流程都沿用同一个选择与结局引擎，存档依据 edition 分别重放。

活动只组织相应版本的决定，不新建暗中数值奖励。反复观察、移动物件和修改数字不能刷取物资；尚未完成的活动草稿不会先写入资源或剧情。操作完成时调用对应原有行动，`choose` 和 `validateBranchState` 继续负责合法性、锁定条件、资源与后果，过期场景不能向新节点提交行动。

## 研究依据

- [refining-game-prototypes](https://github.com/abagames/agentic-gamedev-skills/blob/main/.agents/skills/refining-game-prototypes/SKILL.md)：先检查结构，再检查表现；用同场景证据对照，每次保留有作用的变化。
- [game-design-review](https://github.com/Yuki001/game-dev-skills/blob/main/skills/game-design-review/SKILL.md)：观察、决定、动作、反馈与后果之间要能互相解释。
- [GSAP](https://github.com/greensock/GSAP) 与 [React 使用说明](https://github.com/greensock/react)：将动画限制在真正需要的目标和生命周期，不在每次对白更新时重置整组人物。
- 项目本地的 `design-web-app-miniapp`、`ui-craft` 与 `modern-web-guidance`：语义按钮、焦点、响应式构图与减少运动。外部 CLI 的升级提示没有作为本轮产品需求。

具体测量、保留和未采用的方案见项目 [改进记录](../../REVISION_HISTORY.md)。

## 操作化的原创细节

n10 的“4 件 × 每件 2 枚、实际支付 6 枚”是本作新增的账页示例，不是影片对白或新的资源奖励。数字输入和加减仍可修改；点“核对”即表示征求女工同意并为她核账。错数留在账页提示修改，正确则直接调用核账行动并推进，真实工钱后果继续来自原有规则。

短篇没有把读信变成勾选悲伤知识的练习。读信场景直接听回应与作出决定，避免为缩短后的故事增加无意义的必做步骤。装包与轮值在选齐前可调整，选齐后立即行动；长衫和宽裤铺齐便由姐姐剪发，自己剪发仍可从当前行动直接选择。听对白、写自己的决定与梦境入口保留，不要求完成所有活动。
