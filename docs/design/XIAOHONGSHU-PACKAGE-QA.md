## 画面与清晰度

17幅完整构图覆盖开场、压迫、战争、征用、梦中种子与象王、昏迷／醒来、成长及六个终幕。人物随路线改变动作、伤势、年龄和同伴。父亲双腿完整、跛行与木腋拐；亡兄与幼弟分别呈现；04为露天货斗，05与06不借用“家人已离城”状态。

保留全部PNG母版，原尺寸为1659×948或1672×941。`scripts/encode-six-story-art.mjs --apply`寻找满足38.1 dB门槛的编码，记录原稿和产物哈希至`public/art/sister-v6/encoding-audit.json`；本次最小PSNR 38.1044 dB，透明通道一致，没有缩图。

**WebP RGB为有损编码，不能称为全包无损。** PSNR用于编码误差检查，不等同主观画质认证；本轮另逐幅查看人物与场景。打包阶段再将每幅预制WebP与PNG母版独立比较；缺PNG、尺寸变化、透明度变化或低于38 dB均阻止构建。随后按字节复制WebP，不二次压缩。
