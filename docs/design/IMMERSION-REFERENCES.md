# 《姐姐，我该怎么走》沉浸体验与服饰参考

核验日期：2026-11-07。将用户的“光之遇”理解为《光·遇》（Sky: Children of the Light）。以下将官方表述、影片观察与本项目设计判断分开；不把参考作品的具体 UI 当成可直接复制的模板。

## 三款游戏：可移植的设计原则

| 参考与一手证据 | 本项目的设计判断与落地方式 |
| --- | --- |
| **Sky**：Apple 对 Jenova Chen 的原始采访说明，团队希望屏幕控件不遮挡画面，采用简单、熟悉的操作，并重视情感叙事节奏。[Apple Developer 采访](https://developer.apple.com/news/?id=zm47it7t) | 让彩色场景成为主画面；常驻控件压到边缘，屏幕底部只保留当前阅读与行动。黑白半透明磨砂面板服务文字，不把整张场景切成数据卡片。此处借用的是视觉优先级，不移植飞行操作。 |
| **Florence**：发行商将其描述为关于生活与爱情的互动故事，通过不同互动小片段呈现关系从靠近、争执到成长的变化。[Annapurna 官方介绍](https://annapurnainteractive.com/games/florence) | 每个节点围绕一个情绪或动作组织：先看场景、读一段话，再做一个决定。姐姐的表情、姿态、位置及手中的物品随剧情改变，叙事不只停留在背景切换。 |
| **OXENFREE**：开发商明确说明，对话决定会改变故事与人物关系。[Night School 官方介绍](https://nightschoolstudio.com/oxenfree/) | 把选择写成具体行动或人物说的话；决定后先给可理解的角色反应，再进入后续场景。将累计后果保留到后面的事件与结局，不在每个选项前展示计算公式。当前中文阅读体验不必增加倒计时。 |

这些页面支持设计意图；没有据此声称完整游玩过以上作品，也没有用无法核验的“最受欢迎”排名为方案背书。

## 当前浏览器游戏的实施优先级

1. **场景层**：彩色画面占据主体；人物与物件是故事状态的一部分。进入不同路线时，人物着装、位置、情绪与可见道具都应响应实际经历。
2. **阅读层**：底部单个低干扰磨砂区域承载正文、说话者和姐姐回应。保留全部原文；逐段推进，避免同屏堆满说明、数值和选择。章节与地点可以短暂出现后减弱。
3. **行动层**：读到行动时再展开当前 2–3 个选项；自由输入以“写下另一条路”等明确入口进入。不要让空输入框长期挤占画面。
4. **手记层**：物品、人物状态、走过的节点和结局记录收进可打开的手记。主画面只保留必要入口，且菜单打开时不让背景误触推进。
5. **反馈层**：决定后的角色反应、场景变化和下一步承接要清楚。轻量淡入淡出即可；尊重减少动态效果设置，不强迫玩家等待打字动画。
6. **可用性**：阅读推进与选择都支持键盘和触控；中文输入法组合输入期间不能误触推进。恢复存档要恢复到当前节点和阅读位置；手记可回看已读内容。

上述为本项目判断，不能从参考游戏宣传页面直接推导成经过验证的量化结论。

## 服饰必须绑定具体年代、人物与场合

**历史范围**：《养家的人》的官方发行页明确，Parvana 是生活在 **2001 年阿富汗、塔利班统治下**的 11 岁女孩；父亲被捕后，她剪短头发、扮成男孩以养家。不能把这一具体环境写成所有伊斯兰国家共有的生活方式。[GKIDS 官方电影页](https://gkids.com/films/the-breadwinner/)

**制度与现实差异**：HRW 的原始研究回顾了 1996–2001 年塔利班对女性公开外出的服饰和男性陪同限制，并指出不同地区执行程度与可预测性不同。它支持“公开外出与家内需要区别”，不提供女孩统一年龄门槛或本片衣服颜色。[HRW 原始研究报告](https://www.hrw.org/report/2010/07/13/ten-dollar-talib-and-womens-rights/afghan-women-and-risks-reintegration-and)

**同时期资料**：丹麦移民局 2001 年实地调查报告记录了对联合国机构及当地组织的访谈，描述女性外出需全身遮盖（通常为 burqa）及男性亲属陪同的规定，也记录城乡与地区执行差异；喀布尔的执行尤其严厉。这是丹麦移民局报告，由 UNHCR 的 Refworld 收录，并非 UNHCR 自行发布的调查结论。[报告 §4.4.4](https://www.refworld.org/reference/factfinding/dis/2001/en/23870)

项目组已对用户提供的影片进行抽帧，得到以下**影片观察**，作为本轮资产修改依据：

| 人物／场合 | 已确认的影片视觉 | 本项目的美术处理 |
| --- | --- | --- |
| 姐姐在家内 | 长粗辫、浅橄榄肩巾、红褐长衣 | 保留可见面部、辫子和长衣；用手势、肩部和目光表达状态，不穿现代短上衣或短裙。 |
| 母亲公开外出 | 蓝色全身罩袍、面部遮盖 | 罩袍形成完整外部轮廓；通过身体姿态、手中物品和动作表现剧情。 |
| 女孩原身份 | 绿色头巾 | 与男孩伪装明确区分，不能把成年女性外出服饰自动套到每个儿童身上。 |
| 女孩扮成男孩 | 短发、灰白长衫与宽裤 | 改变发型和完整服装轮廓；不是只在原头像上加帽子或改颜色。 |

姐姐的公开外出版本应依据本故事具体场景和影片对应帧另行确定；不能仅因家内露出辫子就沿用到街市。对同一人物至少区分家内／公开外出／伪装或童话版本。服饰状态应与所在场景、剧情身份同步，避免换了背景而人物仍穿同一套衣服。

影片抽帧由主任务执行者检查；本研究未独立完整观看影片。具体纹样、剪裁、配色及年龄表现以用户影片对应场景为准。
