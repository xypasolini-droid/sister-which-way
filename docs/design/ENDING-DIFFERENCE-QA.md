# 结尾差异与验收记录

版本：0.4.2。日期：2026-11-07。范围：默认八次决定的短篇、结尾投影与终章主屏。以下涉及完整剧透。

## 问题与修复边界

修复前，穷举得到的 **756 条普通现实终局路径**中，`lantern` 有 **660** 条，`caravan` 有 **84** 条，`reunited` 有 **12** 条。多数路径归入留城类别，加上主屏统一的标题与“共同承担”对白，会把已经开课、独住作坊、救父未成、临时借住等不同结果压成相似的体验。梦境入口另藏在面板，也让玩家不容易发现另外两个明确结尾。

本轮没有重配现实分类条件：现实行动仍先检查“父亲为 `free` 且已有 `released`”得到 `reunited`，再检查 `boarded` 得到 `caravan`，其余得到 `lantern`。因此 660 / 84 / 12 的分类计数保持不变，不能宣传为已均衡结局的出现概率。这些数字是对所有合法短篇行动序列的计数，未按真实玩家偏好、锁定选项的可见程度或游玩行为加权。

保存与收藏仍为 **5 个 ID：3 类现实＋2 个成年梦境**。

| ID | 类别 | 现实或愿望中的实际结果 |
| --- | --- | --- |
| `reunited` | 01 现实团聚 | 父亲已经被救出，女主推他回到家人身边；重伤和照护继续存在。 |
| `caravan` | 02 现实离城 | 已确认亲舅舅接应并登上露天后斗货车；父亲仍未获救，前路仍有风险。 |
| `lantern` | 03 现实留城 | 留在城里的具体结果按已发生事实投影，不能统一写成共同生活已经解决。 |
| `dream_guardian` | 04 成年梦境 | 成年女主率全女性卫队守护女性土地，回应曾经无路可走的压迫。 |
| `dream_commons` | 05 成年梦境 | 成年女主、姐姐与莱拉共同建设学校、市场与议事庭，回应学习和发声的愿望。 |

## 第 03 类的五种主屏结果

`getStayEndingPresentation` 统一决定主屏标题、成长说明、两句最后对白、前情回声与代价，`projectEnding` 同时把该结果用于完整结尾。它按下表从上到下选择，不让后匹配的借住或普通留城抹掉更具体的既成结果。

| 优先条件 | 主屏标题 | 普通短篇路径数 | 可见成长与没有解决的事 |
| --- | --- | ---: | --- |
| 已有 `sustained` | 这一回，轮到我读书 | 84 | 女主接过粉笔，也坐进学生的位置；课堂只保住一小时，之后仍要谋生。 |
| 没有前项，姐姐为 `apart` | 姐姐不在身旁的夜晚 | 96 | 女主独自安排住处并承担分别；姐姐今夜不会突然在身边回答。 |
| 没有前项，父亲未获救且历史经过 n25 | 我没能带他回来 | 192 | 女主承认这次救援未成，回去面对家人；下一次机会没有保证。 |
| 没有前项，已有 `settled` 或 `shelter` | 关上门，只借到这一夜 | 96 | 接过照护、接受家人照顾；借住不会自动变成永久住处或街上的自由。 |
| 其余留城 | 天亮后，仍要出门 | 192 | 改变谁能休息、谁来接手一天；劳动、伤势和父亲的空位继续存在。 |

五行合计 **660** 条，都是 `lantern` 类别内的结果呈现，没有增加收藏数量。旧完整篇若同时已经开课、姐姐又分住，课堂成果不会消失，标题为“那一小时，也有我的位置”，正文与最后对白仍承认今夜独住；它是历史状态的兼容呈现，不是新增的第六个结局 ID。

## 终章入口与屏幕内容

n30 现在直接并列 **三个单击行动**：一个符合当前处境的“现实终章”，以及“梦见成年后的我守护女性的土地”“梦见我们一起打开学校和市场”两个“成年梦境”。现实按钮也按前情改变行动文字，点击后直接结算；不再要求玩家另开梦境面板寻找这两条路。

结尾主屏直接显示标题、成长、两句最后对白、前情回声和 `ending.cost`。因此“救父未成”与“开过课堂”的差别不只留在手记；代价也不必再开面板才能读到。梦境保留成年与梦境标记，不改现实父亲、伤势、资源或姐妹状态。
