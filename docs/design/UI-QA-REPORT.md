## 输入与可访问性边界

- 已实际验证中文文本写入、Enter 提交、空输入禁用、错误保留输入、弹窗焦点进入及 Escape 关闭。
- 代码包含输入法组合事件防误提交、弹窗 Tab 焦点约束、状态提示、舞台文字描述、减少动态效果偏好与页面隐藏时暂停。
- 未用真实中文输入法逐字选字测试；没有运行自动无障碍扫描或真实屏幕阅读器。
- 窄屏为桌面 Chrome 模拟，未在实体手机、Safari、Firefox 验证；未测试手机软键盘与低性能 GPU。
- WebGL 不可用时有静态 DOM 舞台回退，未在本次浏览器检查中强制关闭 WebGL。

## 交付边界

适合本机试玩和继续迭代。当前模式是有限规则解释器，不能理解任意剧情，也不实时生成图片或视频。舞台采用原创预制图像与程序动画。

真实模型 API、付费额度、网络超时路径尚未端到端验证；没有配置或调用付费模型。可选 AI 仍受有限世界操作约束。Markdown 导出功能已经实现，但本次浏览器走查未执行文件下载；声音功能未做听感验收。尚未部署公网或配置多人服务。
