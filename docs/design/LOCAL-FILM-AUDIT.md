# 本地影片抽帧核查 · 2026-11-07

本轮为修正《姐姐，我该怎么走》的因果和动作表现，对用户提供的《养家之人》本地视频进行分段图像审阅。电影、电影截图与字幕文件不进入这个公开仓库；本文仅保存核查方法、时间码和简要观察。

## 方法与范围

- 片源：1920×1080、约 93 分 25 秒，含音轨，无独立软字幕轨；画面有烧录中英字幕。
- 使用 [bsisduck/video-analyzer-skill](https://github.com/bsisduck/video-analyzer-skill/blob/main/SKILL.md) 的探测、抽帧、拼图、分段审阅流程，并以本地 FFmpeg/Python 调整长片覆盖策略。
- 原 skill 的自动上限可能令长片只提取前部。此次改为每 10 秒抽一帧，561 帧、36 张拼图，从 00:00 覆盖至 01:33:20；三组审阅覆盖全部拼图。
- 对 10:00–10:58 抓捕、43:40–44:10 首次探监、55:50–56:20 守卫联系人、1:14:40–1:15:58 母亲拒离、1:22:30–1:23:28 营救另以 2 秒间隔密采，查看 132 张补充帧（与基线有部分重合）。
- 另运行全片镜头变化检测：缩至 320 像素宽，scene 阈值 0.25，得到 435 个变化候选。这是辅助定位结果，不等于 435 个叙事场景或对每个候选都完成精读。

这是**覆盖全片时间轴的抽样审阅与关键片段密采**，不是连续听完声轨，也不是逐帧、逐句字幕校对。对两个采样点之间未直接看见的动作，不据此补写为电影事实。时间码对应这一份片源，其他发行版可能不同。

## 不能混为电影事实的设计

游戏更换了人名与部分地点，采用压缩的日次，并增加私人课堂、证词、名册、编号、私宅借宿与多种分支结局。它们可以作为虚构叙事机制，但不代表当时真实存在标准化办事窗口，也不是电影逐场复刻。原创机制本身仍要保证谁知道什么、谁在场、为何受伤、何时换装以及行动结果的连续性。

女性公共外罩、儿童头巾、室内肩巾及待售的鲜艳衣物需分开看；片中确有绿、蓝、红等颜色，不能归纳为“所有头巾必须黑色”。有关历史限制的说明限定到影片所描写的时间地点，不推广到所有穆斯林社会。
