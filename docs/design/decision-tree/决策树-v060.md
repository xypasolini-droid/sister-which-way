# 0.6.0 六条命运

以用户新图为依据。四处分叉、九个选项、六条完整路线，每局两至三次决定。下表时长为镜头总和，不含玩家思考、暂停与重看。

| 终幕 | 稳定行动 ID | 表现类型 | 自动镜头时长 |
| --- | --- | --- | --- |
| 01 没有升起的炊烟 | stay_long → refuse | reality | 118秒 |
| 02 姐姐出嫁的那一天 | stay_long → accept | reality | 119秒 |
| 03 没有返程的路 | cut_hair → flee | reality | 132秒 |
| 04 离城的四个人 | cut_hair → home | reality | 132秒 |
| 05 没有醒来的春天 | cut_hair → friend → dream | dream | 204秒 |
| 06 守护之地 | cut_hair → friend → wake | future | 221秒 |

`reality` 为现实分支，`dream` 为未醒的梦，`future` 为醒来后的原创未来。05与06的现实家人去向未知。
