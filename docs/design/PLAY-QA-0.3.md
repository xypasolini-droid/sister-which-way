## 上一轮浏览器走查（移除额外确认前）

测试使用与用户原 3000 来源分开的 localhost、3001 测试进度，没有重置用户原来的存档。桌面 1280×720、手机视口 390×844；使用真实按钮和输入，没有注入存档跳关。

1. 开场把纽扣收进布包，再取出，再收进；物件与计数真实改变。收进/取出后键盘焦点转到对应按钮，用 Enter 也能完成。选择两件后出现明确的收摊确认。
2. 听对白再返回操作时，未确认的布包草稿保留；刷新恢复已确认故事与所在幕次，临时物件草稿按设计重置。
3. 在变装场景测量七个人物槽位，阅读与行动模式的计算位置、宽高、透明度、变换相同。普通切换不再重播整组演员入场。
4. 实际推进 n02 四拍抓捕，最后父亲离场。减少运动模式也保留离场结果；n06 两句过场交代母亲遭打与买饼受拒，随后准备亡兄衣物。
5. 开发版完整走完救父路线，共八次决定，立即到达“五个人的黎明”：

   `n01 work → n02 sew → n06 buy → n07 truth → n09 courier → n18 plan → n25 release → n30 live`

6. 上一轮生产版开启减少运动，完整走过第二条路线，经过工钱核算，立即到达“关门以后，还有一堂课”：

   `n01 work → n02 sew → n06 help → n07 hide → n10 ledger → n18 rush → n22 school → n30 live`

7. 工钱核对先用 6 得到可修改的差额说明，再用数字输入、加号改到 8；没有扣除惩罚资源或自动提交下一幕。手机视口也操作加号、核对与最终确认，画面没有横向溢出。
8. 从课堂结局撤回，恢复第八幕，再进入“守护之地”梦境；标题明确标梦境，成年主角与现实家人分开。梦境后重开短篇，结局收藏保留。
9. 上一轮生产版测试页所记录的 warning/error 日志为空。开发组装期间曾短暂出现模块尚未落盘的热更新错误，模块完成后生产构建与路线未复现；不把组装期间日志说成从未有过。
10. 上一轮交付页面为 `http://127.0.0.1:3001/`。该来源随后由用户继续试玩，本轮没有重置它；原 `http://127.0.0.1:3000/` 页面与进度也保留。

## 当前版：选择即推进

用户指出衣物选择后还要点“选择下一步”造成多余操作，当前版已移除这层流程。以下在 `http://localhost:3001/` 的独立测试进度中完成；没有注入存档或改用户当前的 `127.0.0.1:3001` 进度。

1. 开场只收纽扣时停在第一幕；再收布料立刻进入第二幕抓捕演出，无收摊确认。
2. 抓捕四拍演出后，直接点“先写下回家约定，再随母亲走”就进入第三幕。
3. 第三幕选长衫时停留；再选宽裤立刻换成男装并进入第四幕。没有“选择下一步”或最终行动确认。另一种剪发方式标“或”，表示替代行动。
4. 点作坊修补行动立刻进入第五幕。工钱为 6 时点“核对”会留在账页并解释差额；加两次到 8，再点“核对”立刻到第六幕。
5. 第六幕点“私院”直接到第七幕；轮值表第一项只暂存，第二项选齐直接到第八幕；点生活约定直接显示“关门以后，还有一堂课”。本条路线共八次剧情决定：

   `work → sew → buy → hide → ledger → rush → school → live`

6. 从结局正常撤回第八幕，确认“写自己的决定”直接打开输入并获得焦点，回到场景后“做一个梦”可打开两个梦境选项。
7. 手机视口 390×844 中检查加号、错账提示、正确核对及路线操作，无横向溢出；路线的风险说明保留显示。临时视口在测试后恢复默认。
8. 最终构建重新载入后，复核衣物选齐推进与替代行动标识，测试页 warning/error 日志记录为空。
9. 组件去重后的所有普通行动另由独立代理穷举审查：30 个完整篇节点、1198 个短篇未结束状态中的 3531 个可用行动均有直接热点或活动入口，未发现分支遗漏。此为规则检查，不宣称手动玩完全部路线。

单选、收齐、正确核账的解析函数单独覆盖未完成、错账、缺钱、缺粮、身体条件、未知 ID、真实路线 ID、短篇目的地及不提前改资源；界面与最终 `choose` 继续验证条件。快速重复同幕提交仍由 `routeRef` 拦截。
