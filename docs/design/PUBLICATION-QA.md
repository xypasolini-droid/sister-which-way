## 实际浏览器走查

使用独立来源的测试存档，没有重置用户原来正在游玩的进度。检查桌面 1280×720 与手机视口 390×844。

1. 开场父亲与女孩分别使用坐席读信、整理货物的动作图，物件与人物位于同一摊席；手机画面保留两人，没有横向溢出。
2. n02 逐句推进抓捕，父亲向门口移动后离场，母亲起身阻拦；行囊明确写出父亲在全家面前被抓走，不再把被捕写成不明失踪。
3. 开发版刷新与源文件热更新未出现截图中的 AbortError；刷新后保留此前对话位置。
4. 生产版通过实际点击 17 次行动，走过以下路线并到达 **“五个人的黎明”**，没有用存档注入直接跳到结局：

   `n01 → n02 → n03 → n04 → n05 → n06 → n07 → n08 → n10 → n11 → n14 → n16 → n17 → n18 → n23 → n25 → n30 → 结局 01`

5. 这条路线实际检查了读信／识字与看守的关系、母亲返回的对白、家人重新在场及父亲获救后靠在木推车上。母亲说出“贾维德逼我们走。我不能丢下你。”，不是无说明地重新出现。
6. 生产版这条完整路线的浏览器日志未出现 warning 或 error。最后的日次、面饼和伤势播报补丁完成自动回归后重新构建；没有声称又人工重走了一遍全部路线。
