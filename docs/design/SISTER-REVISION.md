# 姐姐，我该怎么走 — 分支叙事修订

> **历史版本设计记录。** 本页记录八结局阶段的目标与旧界面合同，保留当时方案供追溯，不代表当前 0.4.0 的八幕短篇、五结局或界面。当前功能以 [README](../../README.md) 为准，新版走查范围见 [PLAY-QA.md](PLAY-QA.md)；较早的十结局发布检查保留在 [PUBLICATION-QA.md](PUBLICATION-QA.md)。

## 可观察目标

玩家扮演12岁的努拉，在虚构山城萨岚与姐姐玛莉安共同寻找生计、照顾母亲、追寻被带走的父亲。每个选择都应产生具体事件、资源与关系变化，影响后续可走的路线。30个节点是整张分支图的规模，单局经过其中一条路径；8种结局需要实际可达。

故事参考《养家的人》中严苛统治下的家庭生计与故事维系希望的主题。背景明确为原创架空国家中的特定武装政权，不把压迫概括为所有穆斯林或伊斯兰国家的共同生活。普通居民、医师、手艺人和邻居有不同立场与互助行动。人物和对白为原创。

来源核对：[GKIDS官方介绍](https://gkids.com/films/the-breadwinner/)、用户提供的《养家之人.mp4》（本地抽样查看，非完整逐镜观看）。游戏不嵌入电影音视频。

## 视觉与交互合同

- 按用户最新要求使用黑白灰界面与透明磨砂玻璃：浅灰底、黑色文字与按钮、白色半透明面板、背景模糊与细亮边；人物、场景和道具保留彩色。采用中文衬线叙事正文与无衬线操作文字。
- 主任务：阅读当前具体困境，选择或输入一个行动，观察事件、人物、物资的改变。
- 桌面主列为场景、后果、当前剧情、2–3个可执行决定；侧页展示姐姐、关系、家人处境与物资。移动端单列，按钮至少44px触控高度。
- 角色服装是真素材切换；姐姐可以离场、疏远、受伤和重逢；父亲救出后入场。信件、药物、粮食、检查点通行等随状态改变。
- 现实层有不可兼得的代价；姐姐讲述的童话是希望和记忆，不是消除现实风险的魔法。
- 默认不联网模型也可完整游玩；打字映射到当前节点现有行动，无法理解时保留文字并说明。可选AI仅解释意图，不编造不存在的分支。
- 撤回一步同时恢复故事和场景；当前存档与结局图鉴分开保存，重开不清空已解锁结局。
- 结局图鉴未解锁项不提前展示正文；已解锁可回看。故事手记可导出。

## 验收要求

节点与结局数量检查、全部节点及八结局可达验证、条件限制、原子变更、存档验证、文字匹配、不同选择确实影响后续路径。浏览器验证至少一条完整路线、人物服装变化、姐姐状态、撤回续玩和窄屏。
