# 单选分路与冲突分镜 · 设计约定

本轮以用户最新反馈为准：取消装包、整理衣物、轮值配对和算术小游戏。玩家看清眼前发生的冲突，再从现有行动中单选一条路。选择后直接推进，不增加准备任务或最终确认层。默认短篇仍是八次剧情决定、五种结局；镜头数量不计入决定次数。

本文是当前方向与实现边界，不是浏览器验收报告。此前的场景活动方案与测试保留在历史记录中；当前真实操作、截图、测试及未验证范围以 [可玩性验收](PLAY-QA.md) 为准。

## 方向合约

| 项目 | 约定 |
| --- | --- |
| 主张 | 让玩家看见谁在施压、谁受到伤害，以及家人怎样继续前行；每场的主要操作只有选择行动 |
| 对象与场合 | 在桌面或手机浏览器里游玩中文短篇的人；鼠标、触摸与键盘均可完成核心流程 |
| 信息任务 | 先辨认人物和正在发生的事，再理解两至三条行动的差别与受限原因 |
| 色彩角色 | 页面底色 `#111111`；主要文字 `#f5f5f3`；辅助文字 `#c4c4c4`；玻璃表面 `rgb(17 17 17 / .74)`；玻璃边线 `rgb(255 255 255 / .19)`；键盘焦点 `#ffffff`。沿用项目现有语义值，人物与背景保留彩色 |
| 字体 | 沿用 `--serif` 承载故事与行动，`--sans` 承载控制、身份与简短说明；使用现有中文回退字体，不引入装饰字体 |
| 构图 | 顶部只留地点、幕数和少量工具；人物与冲突占据中央；底部黑白磨砂层放说话人、短字幕或单选行动。手机重排文字与控件，给人物面孔和施压动作留出位置 |
| 识别特征 | 同一片彩色纸片舞台里，人会靠近、阻挡、跌倒、扶起和离去；后果通过身体与空位可见，不只替换背景或正文 |
| 视觉取舍 | 将表现力用于具体事件和表情姿态。玻璃面板保持安静，普通切句不重播整组人物入场，不增加漂浮装饰和循环粒子 |
| 运动姿态 | 关键冲突为一次性自动分镜；普通阅读与决定保持稳定。演出可暂停、跳过、重看，减少运动时仍保留各拍姿态与事实 |
| 文案姿态 | 按钮直接写行动结果；字幕尽量不超过二十六字。使用“巡查”“摊主”“贾维德”等具体身份，不用抽象文化标签代替施害者 |

这套方向沿用项目的 `design-web-app-miniapp` 与 `ui-craft` 方法：先固定主要任务、真实状态和方向合约，再检查运动是否解释因果。用户已明确选择黑白玻璃与彩色场景，视觉调整不另起一套品牌或字体系统。

方向检查的结论是将新表现集中在冲突演出。此前“做准备再行动”的小游戏增加了操作，却延迟了用户想作出的决定，因此本轮删除。新增表情与姿态服务于具体事件，不把小游戏换成另一套必须完成的收集或测试。

## 核心流程与状态

`进入当前幕 → 可选的自动分镜 → 当前单选行动 → 原有规则写入后果 → 下一幕／结局`

- **单选行动**：点下即调用对应现有行动；不要求整理道具、答题或再点“选择下一步”。受限行动仍显示原因，可选其他合法行动。
- **演出播放中**：提供暂停／继续、跳过、重看。自动计时只切镜头，不提交剧情选择；跳过回到当前幕行动，重看回到同一段开头。
- **听他们说**：继续保留短对白阅读，给需要更多人物回应的人使用。
- **写自己的决定**：继续匹配当前已编写且可执行的行动；输入歧义、冲突或不匹配时保留文字并说明怎样修改。
- **童话与梦境**：关键童话保留独立视觉层；终章保留两个明确标示的成年愿望梦境入口，梦境不修改现实中的伤势、物资或父亲状态。
- **中断与恢复**：真实进度以分支存档为准。播放位置与暂停是表现状态，不能把看过、跳过或重看的镜头重放成资源变化。
- **加载或素材失败**：保留地点、说话人、短字幕与跳过／行动入口，不以图片是否加载完成决定玩家能否继续。

| 节点 | 顺序与应看见的事件 | 场景连续性 | 单拍停留 | 减少运动后的等价信息 |
| --- | --- | --- | --- | --- |
| n01 · 赶摊 | 年轻巡查指责女孩 → 举棍逼近，父亲护住女孩 | 集市两拍 | 2.4–2.6 秒 | 显示巡查的阻挡与父亲护人的不同定格 |
| n02 · 抓捕 | 踢门闯入 → 抓住父亲 → 拖向门口、推开母亲 → 父亲离场，留下翻倒的碗 | 家中四拍 | 2.4–2.8 秒 | 父亲仍按节拍离开；不能只剩一段“突然不见”的文字 |
| 短篇 n06 · 此前的遭遇 | 母女被拦 → 母亲求问 → 棍落、蜷身 → 女孩扶母；随后推回零钱 → 巡查举棍 → 女孩被逼退；最后母亲养伤、女孩空手回家 | 检查口四拍 → 集市三拍 → 家中一拍；标示“此前” | 2.4–2.8 秒 | 八拍事实和地点变化保留，取消猛烈位移；之后回到家中作当前决定 |
| 完整篇 n03／n04 | 沿用母亲遭打四拍／拒售三拍 | 各自对应检查口／集市；不在完整篇 n06 重播合并过场 | 2.4–2.8 秒 | 保留同样的施压、受伤与退回事实 |
| n07 · 男装也不安全 | 武装者喝令两个孩子搬军需 → 孩子退到摊后 | 集市两拍 | 2.5 秒 | 武装者的喝令与孩子退避的姿态可辨认；不自动写入参军或受伤后果 |
| n08 · 盘查 | 巡查指着孩子，要求戴小帽的孩子开包 | 检查口一拍 | 2.5 秒 | 仍按已换男装的外观与“小子”称呼演出，不套用母女旧装 |
| n21 · 强迫带离 | 远亲催上车 → 扯住母亲 → 母亲挣开并拒绝丢下女儿 | 路边车旁三拍 | 2.5–2.8 秒 | 母亲拒绝是她自己的行动，不由玩家替她或姐姐答应婚事 |
| n25 · 门外战火 | 枪火逼退人群 → 女孩躲到侧墙 → 阿明给出条件相符的回应 | 监所三拍 | 2.3–2.8 秒 | 保留掩护位置和回应，不使用闪烁或强烈震屏替代可读事实 |
| 普通阅读与单选 | 同场人物保持位置、比例与在场状态；只有真实行动后果改变舞台 | 当前场景 | 无强制演出 | 与普通模式呈现相同状态与行动入口 |

播放时只推进当前镜头索引；暂停停留在可读镜头；跳过落到当前幕的单选行动；重看不重置剧情。真实换场或角色离场可以过渡，普通切字幕不触发整组重新进场。无声、减少运动和静态姿态均应传达同样因果。

## 人物与美术边界

现行压迫者与情绪姿态位于 `public/art/sister-v3/`，是参考本项目原角色重绘的手绘透明 PNG，包括巡查、摊主、武装者、远亲、被带走的父亲、护头及倒地的母亲、扶人和害怕的女孩。原几何 SVG 人物稿已退出运行时；错误父亲 SVG 与生成逻辑已移除。车辆和梦境背景仍使用 `oppression/`。这些素材不是从电影截图抠出的人物，也不声称是影片原始资产或逐帧动画。

画面需要明确区分举棍、棍落、受伤、扶起与逃离，字幕不能声称镜头中没有的动作。表现伤害以姿态、距离和可见后果为主，不用玩家的操作速度或正确率解释受害者是否挨打。

巡查负责公开威胁与殴打，摊主在巡查在场时拒卖，贾维德强迫家人离开。限制被放在具体政权、时期与原创山城的故事处境中，不能从这些人物的行为推出整个伊斯兰文化、所有阿富汗人或所有男性的共同性格。服装继续跟随人物身份、公开／私下场合、剪发和受伤状态。

本作仍是参考电影主干的原创分支故事。镜头对白为本作重新编写，局部影片观看与有来源的研究不等于完整逐帧复刻，也不等于真人历史学者认证。依据及未核实部分继续见 [影片核查](FILM-CONTENT-REVIEW.md)、[历史文化核查](HISTORICAL-CULTURAL-REVIEW.md)与[本地抽样审计](LOCAL-FILM-AUDIT.md)。

## 剧情与规则边界

| 边界 | 约定 |
| --- | --- |
| 真实状态 | `getOppressionShots` 只读取节点、版本、结局与标记，返回演出数据；不修改家人、资源、历史或结局 |
| 行动与存档 | `choose`、原有锁定条件和按版本重放继续决定真实后果；保留行动 ID 与效果以兼容已有记录 |
| 救父 | 只有既有读信与识字往来满足 `guardBond` 时，阿明才表现愿意进去找人；仍需原有条件才能选救援，不在入场演出提前带出父亲 |
| 暴力与拒售 | 自动呈现既定事件，不设计“点得够快就不会挨打”或“答对才值得获得帮助” |
| 母亲与姐姐 | 母亲拒绝强迫带离，姐姐保留拒婚与表达意见的主体性；女主不在场时不替她们发言 |
| 回看与跳过 | 看、暂停、跳过、重看均不新增决定，不奖励或扣除物资；终局不再自动插入冲突演出 |
| 结局数量 | 保留三个现实成长结尾与两个成年愿望梦境；自动镜头不增加第九次决定 |

## 验收交接

本合同要求检查单选直接推进、暂停／继续、跳过、重看、键盘焦点、手机布局、减少运动、真实镜头与字幕对应，以及完整八次决定后的结局。必须分别记录规则测试与浏览器实际观察；代码存在、设计表完成和旧截图均不能代替本轮验收。当前结果由 [PLAY-QA.md](PLAY-QA.md) 维护，本文不填写尚未取得的通过结论。
