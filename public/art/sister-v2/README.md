# 《姐姐，我该怎么走》人物第二版

本目录为 2026-11-07 根据用户提供的《养家之人》片段服饰参考新绘制的游戏角色。不是电影帧裁切素材。故事人物继续使用原创名字努拉、玛莉安；形体由第一版的圆润造型改为清晰的二维几何轮廓、纤细长鼻、小眼和克制表情。全部图像使用 imagegen 逐项生成/参考编辑，随后仅以 ffmpeg 做透明画布尺寸、留白和基线规范化。旧版 `../sister/` 未覆盖。

## 尺寸与舞台基线

- 原有 20 张现实/梦境人类角色 PNG 为 **512×1024 RGBA 真透明**。本轮另加 4 张 **887×1774** 动作变体，见文末。另有 `tale-flame.png` 为 **512×768** 的透明童话角色。
- 原有 20 张人类角色可见实体的最低脚底像素为 **y=1010**（从 0 开始）；新动作图保留生成画布并由舞台单独缩放，不能套用此基线。童话火苗使用独立画布，见下文。
- 基线以 alpha >127 的可见实体计算。生成图边缘的极低透明抗锯齿像素可能越过可见边界，不应用全 alpha 非零包围盒定位。
- 坐姿人物仍保留原人物比例：头顶在画布高度约 25–27%，不将坐姿放大成站姿高度。
- `asset-manifest.json` 记录实际尺寸、可见包围盒、透明比例与脚底基线。
- `clinic-exterior.png` 与 `dream-land.png` 为 1280×720 的不透明背景。

## 服饰参考边界

蓝色罩袍、女孩头巾与姐姐的家内服饰取自用户提供影片的具体造型参考，不主张这些服饰是所有穆斯林家庭、所有国家、所有时代的统一服制。公共、家庭、女性诊疗空间的区分由场景语境决定，不按绝对年龄阈值切换。文化与历史说明见项目 `docs/design/HISTORICAL-CULTURAL-REVIEW.md`。

参考抽样保留在工作目录 `work/costume-reference/contact.jpg` 与 `work/sister-reference/contact.jpg`，原片仍留在用户提供的路径。发布目录不包含电影截图。

## 可复现提示词

`prompts.json` 保存初期生成的完整提示词，其中 `sister-outdoor` 为初稿，最终文件使用 `sister-outdoor-fixed` 的密织网窗修正版。每个变体通过已完成的同人物参考图编辑，保持衣着、身份和画风一致。姐姐受伤状态为脚踝扭伤；母亲受伤状态为前臂包扎与眉骨瘀青，二者不混用。

## 小帽与颜色复核（2026-11-07）

再次目视用户影片抽样 `work/sister-reference/contact.jpg`：左上是女童青绿头巾；左下帕瓦娜室内为短发无帽；右下帕瓦娜在狱门处确有浅灰小帽、褐色帽带、米灰长衫和布挎袋。另 `work/costume-reference/contact.jpg` 可见姐姐浅橄榄肩巾及成年女性蓝色全身罩袍。因此保留现有低饱和深绿、橄榄、蓝灰配色，不把衣着统一改成黑色，也不添加鲜艳花饰。帽子的识别依据是本地电影画面；不把帕瓦娜与另一位男装女孩肖齐娅混为一人，不声称帕瓦娜在影片中一直戴帽。

联网复核了 [GKIDS 官方影片页及官方预告入口](https://gkids.com/films/the-breadwinner/)、[Universal 官方影片页](https://www.universalpicturesathome.com/movies/the-breadwinner) 和[影片制作方学习指南](https://mediafiles.cineplex.com/Theatres/GroupSales/CorporateScreenings/TheBreadwinnerStudyGuide.pdf)。官方文字确认帕瓦娜剪发扮男孩，肖齐娅是她另一位同伴；衣物颜色和小帽的具体判断以已查看的用户原片帧为直接证据。

根据本次用户要求，通过内置 imagegen 给 `hero-worker.png`、`hero-travel.png` 添加朴素浅灰小帽，其他人物和背景没有改变。编辑提示词另存 `cap-edit-prompts.json`。原无帽图保留为 `*-indoor.png`，适配公共/私密场景切换；这一批 512×1024 人物共用 y=1010 的可见脚底基线；文末新增动作图单独处理。

## 梦境结局与连续童话（2026-11-07）

`dream-guardian.png` 和 `dream-land.png` 仅用于两条明确标示的愿望梦境结局。成年努拉与女卫队城市不是对现实历史的描述，也不是现实剧情中突然实现的奇迹。城市包含女孩学习、女性阅读交易和守护城门的日常愿望，避免宗教建筑符号拼贴与伪文字。角色脸型和深绿色继承努拉，身形与衣着表现成年成长。

`tale-flame.png` 用于 n05/n07/n20/n25/n30 穿插的连续火苗故事，可叠在 `../scene-forest.png` 上。它的画布为512×768，可见实体范围 x=22–476、y=32–737，透明四周含轻微暖色光晕。此图不使用人类角色的 y=1010 基线。

`guard-amin.png` 是现实故事中愿意冒险帮助家人的看守角色，画风与普通人物一致，避免将其画成无差别威胁剪影。以上四图均由内置 imagegen 新绘，提示词保存于 `dream-tale-prompts.json`；原片截图没有进入发布图像。

## 动作补充素材（2026-11-07）

`father-market.png`、`hero-market.png`、`mother-stop.png`、`father-rescued.png` 为内置 image_gen 基于本作原有人物生成的透明动作变体，实际画布为 **887×1774**。它们分别用于坐席读信、整理货物、起身阻拦和获救后的推车休息；舞台为这些姿势单独设置尺寸，不适用旧人物 512×1024 的画布约定。完整提示词见 `action-pose-prompts.json`，实际尺寸与透明区见 `asset-manifest.json`。原有素材保留。
