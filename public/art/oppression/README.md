# 关键冲突动作素材

这组透明矢量人物曾用于《姐姐，我该怎么走》的 0.4.0 冲突演出，现已退出人物运行时。它们以本作原有低饱和剪纸人物为视觉参照，由代码绘制，没有裁切电影帧、嵌入照片或调用付费生成服务。所有 SVG 保留可编辑的身体、头部、手臂和道具分组；通过 `<img>` 使用时需要切换姿态文件，不能从外部 CSS 直接选中 SVG 内部的手臂。

**父亲旧稿更正（2026-11-07）：**本目录原先依据“缺腿／空裤管／单腿”的错误推断绘制父亲，现已撤回该判断。用户明确确认的游戏设定是**父亲双腿完整、跛脚，行走需要拐杖，不是截肢**。五张错误父亲 SVG 已从当前目录移除，并从旧生成脚本中删除对应生成逻辑。现行造型使用 sister-v2 的坐姿／推车 PNG 与 sister-v3 的站姿／被带走 PNG；已不再接入旧稿。旧稿只留在 Git 历史中。

## 服饰与叙事边界

人物属于本作虚构城市和具体冲突，参照约 2001 年阿富汗的影片语境。长衫宽裤、朴素小帽、头巾、外罩的颜色与轮廓不被声明为整个伊斯兰世界的统一服制。成年母亲在公共街道使用带密织面窗的全身外罩，不是露眼缝的面纱；蓝灰色服装不会在遭打时突然露出脸。家中抓捕另沿用本作原有家居服母亲动作 PNG，避免把公共外罩穿进原本的家庭场景。

压迫者的威胁由手势、武器、接近位置和台词共同表达。素材不带血腥伤口。友善看守阿明沿用独立人物素材，不与这组攻击性人物混用。

## 再生成与验证

`build-assets.py` 仅保留历史几何人物稿的生成能力，已排除父亲；现役人物请使用 sister-v2/v3 PNG，不要重新接入这些几何旧稿。`asset-manifest.json` 记录实际 SVG 渲染后的透明比例及实体包围盒，由项目已安装的 `sharp` 在校验时生成。该清单只记录历史几何稿，不代表现役手绘人物。

五个错误父亲输出及对应绘制逻辑已移除；旧版 `asset-manifest.json` 中的历史父亲记录也已剔除。当前制作要求以上方用户确认设定为准。

本目录只记录创作来源，不对整个项目增设或推断统一开源许可证。
