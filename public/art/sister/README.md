# 《姐姐，我该怎么走》原创美术资产

2026-11-07 使用内置 `image_gen` 生成。全部为本游戏新创作的插画，未从电影截取角色或背景。用户提供的视频仅用于研究现实层的克制人物表现、土黄泥砖、灰蓝和绿头巾，以及平面纸材的视觉方向。

## 场景

八张 836 × 470 RGB PNG，统一正面舞台视角，前景留出人物活动空间。

| 文件 | 场景 |
| --- | --- |
| home.png | 家庭室内、空碗、折叠被褥 |
| market.png | 褪色棚布与集市摊位 |
| workshop.png | 裁缝桌、缝纫机、布料 |
| courtyard.png | 石榴树与院门 |
| clinic.png | 诊所、病床、药架 |
| checkpoint.png | 街口路障与岗亭 |
| prison.png | 拘留所外墙、铁门和长凳 |
| road.png | 山路、旧巴士与行李 |

场景由两张 2 × 2 图集精确裁切。第一组做过一次生成式修订，移除了华丽瓷砖与密集纹样，保留朴素的日常生活环境。

## 人物

人物均为 RGBA 真透明 PNG，头脚不截断，朝右侧的四分之三视角。三套主角衣服使用同一次生成中的同一角色设计。

| 文件 | 尺寸 | 表现 |
| --- | --- | --- |
| hero-cloak.png | 512 × 1024 | 努拉，红头巾、长辫、赭黄上衣，忧虑姿态 |
| hero-worker.png | 512 × 1024 | 努拉，短发、灰蓝工作服，坚定姿态 |
| hero-travel.png | 512 × 1024 | 努拉，旅行外衣、红围巾、背包 |
| sister.png | 400 × 1024 | 玛莉安，深绿头巾、藏青裙，伸手引导 |
| sister-injured.png | 370 × 1024 | 同一姐姐，坐姿、单侧脚踝白布绷带，双手放膝上，无血腥 |
| mother.png | 400 × 1024 | 母亲，紫色头巾、坐姿 |
| father.png | 356 × 1024 | 父亲，灰色长衣、疲惫站姿 |

脚底大致位于图高 95–96%；坐姿人物保留同样脚底基线，自然降低头部高度。各图宽度不同，按固定高度或 `object-fit: contain` 显示，不要强制拉伸成相同比例。

## 可随剧情改变的物件

六张 512 × 512 RGBA 透明 PNG：`bread.png`、`medicine.png`、`letter.png`、`book.png`、`bag.png`、`lantern.png`。无文字标签，舞台可根据拥有/失去状态显示或隐藏。

## 生成与验证

- 内置 image generation：两组背景、主角换装图集、家人图集、道具图集；背景第一组另有一轮生成式修订。
- 仅用 FFmpeg 将图集拆成独立资产，未用程序绘制或改造角色。
- 已目视检查全部生成图集及裁切后的主角、姐姐；已核对全部图像尺寸和模式，所有角色/道具 alpha 均包含 0，是真透明。
- 每次生成的完整提示词与用途存于 `prompts.json`。
- 当前文件已经复制到项目内；不依赖生成工具缓存目录。
- 受伤姐姐已在生成式编辑中从手臂吊带修正为脚踝绷带，以对应 n18 / n24 的脚踝扭伤情节。保留同一人物、服装、坐姿、透明画布与脚底基线；生成后仅作尺寸归一化为 370 × 1024。
